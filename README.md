## Задание 1: Юнит-тесты

** В рамках проекта по автоматизации тестирования веб-приложения Stellar Burgers была разработана и протестирована модель бургера – класс Burger. Цель тестирования – проверить корректность работы всех методов класса, включая добавление ингредиентов, перемещение, удаление, расчёт цены и формирование чека.

Тестирование выполнено с использованием pytest, unittest.mock и pytest-cov для измерения покрытия кода.

### Реализованные сценарии

Созданы юнит-тесты, покрывающие классы `Burger`

Процент покрытия 100% (отчет: `htmlcov/index.html`)

### Структура проекта

- `praktikum` - пакет, содержащий код программы
- `tests` - пакет, содержащий тесты, разделенные по классам. Например, `bun_test.py`, `burger_test.py` и т.д.

### Запуск автотестов

**Установка зависимостей**

> `$ pip install -r requirements.txt`

**Запуск автотестов и создание HTML-отчета о покрытии**

>  `$ pytest --cov=praktikum --cov-report=html`
